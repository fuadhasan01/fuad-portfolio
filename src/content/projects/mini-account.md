## Overview

The Mini Account Management System provides core double-entry bookkeeping functionality, allowing businesses to organize general ledgers, track account hierarchies, and generate balanced vouchers.

## Implementation Details

- **ASP.NET Core Razor Pages:** Server-rendered UI for high-efficiency data entry.
- **Relational Integrity:** Microsoft SQL Server backing ledger entries with strict transactional balance constraints.
