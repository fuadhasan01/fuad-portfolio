## Overview

LibraryMS is an enterprise-ready multi-branch library system designed to handle cataloging, circulation, member borrowing records, and automated fine calculations.

## Technical Architecture

- **Modular Backend:** ASP.NET Core REST APIs structured around domain boundaries.
- **Containerized Deployment:** Docker container configuration for local database and API consistency.
